# 鸡狗杀 · JIGOUSHA

> **MyGO!!!!! × Ave Mujica** 五人身份卡牌对战
> 同人二次创作 · 非官方作品 · 仅供娱乐

「鸡狗」来自中文圈对两部作品的爱称：**母鸡卡**（Ave Mujica）与 **卖狗**（It's MyGO!!!!!）。
玩法骨架取自身份暗牌类卡牌（三国杀式），但身份、角色、技能、卡牌全部按两部动画的人物关系重写。

## 一、怎么玩

### 经典模式（单机，无需联网）
直接双击 `index.html` 即可。
1. 选择角色：11 名乐队成员（卡面带立绘与技能）
2. 身份在开局时**随机分配**（制作人/共演者/拆团者/独演者）
3. 与 4 名 AI 同台，直到分出胜负

### 联机模式（5 人房间）
双击 **`开始游戏.bat`**（或在本目录执行 `node server.js`），
浏览器访问 <http://localhost:8787>。

1. 输入名字 → **创建房间**，得到 4 位房间码
2. 朋友输入房间码加入（空位可由房主点 **AI 补位**）
3. 全员准备 → 房主点 **开始演出**（身份当场随机分配）
4. **选择角色**：5 人同时选，重复选择按座位顺序裁定，后选者重选
5. 对局开始。同一浏览器断线后重新进入会自动尝试回到原座位；掉线超过 40 秒由 AI 托管。

> 需要 Node.js 18+，服务器零依赖，不用 `npm install`。

**和朋友联机**：同一局域网内，让朋友访问 `http://你的内网IP:8787`（例如 `http://192.168.1.10:8787`）即可加入房间；
跨公网需要做端口映射或用内网穿透工具，把 8787 端口暴露出去。

## 二、身份

5 人局固定构成：**制作人 ×1、共演者 ×1、拆团者 ×2、独演者 ×1**。
每局开始时**随机分配**，除制作人外，所有人的身份都是暗牌。

| 身份 | 人数 | 胜利条件 | 身份效果 |
|---|---|---|---|
| **制作人** | 1 | 让拆团者与独演者全部退场 | 身份公开；体力上限 +1、手牌上限 +1 |
| **共演者** | 1 | 保护制作人活到谢幕 | 体力上限 +1；技能「和声」 |
| **拆团者** | 2 | 制作人退场即胜（即使自己已退场） | 技能「拆解」 |
| **独演者** | 1 | 成为唯一还站着的人 | 技能「独演」 |

- **和声**（共演者）：每当制作人受到伤害时，你可以弃置一张手牌，**代替其承受此伤害**（每回合限一次）。
- **拆解**（拆团者，锁定）：你退场时，其他拆团者各摸一张牌。
- **独演**（独演者，锁定）：你的手牌上限 +1。

> 制作人公开身份，因此天然成为靶子；共演者要藏好自己，拆团者要互相寻找，独演者要在两边之间走钢丝。

## 三、回合流程

```
准备阶段 → 判定阶段 → 摸牌阶段（摸 2 张）→ 出牌阶段 → 弃牌阶段 → 结束阶段
```

- **手牌上限** = 当前体力（另有技能/身份修正）
- **攻击范围** 默认 1；装备武器后按武器数值计算
- **距离** = 座位间最短距离 + 目标防御坐骑 − 你的进攻坐骑（最低 1）
- **濒死**：体力 ≤ 0 时进入濒死，任何角色可对其使用【抹茶】（或技能）救援；无人救援则退场
- **击杀奖励**：击杀拆团者摸三张牌；击杀共演者需弃置所有手牌；拆团者退场时其他拆团者各摸一张
- **终幕**：第 30 轮起，每名角色的回合开始时失去 1 点体力（防止僵局）
- **终幕距离**：第 20 轮起 / 仅剩两人时，全场距离视为 1

## 六、界面速查

- **开局**：先播一段「身份抽取」动画——五张身份牌洗牌、飞向每位玩家，然后翻开你自己的身份（制作人会被公开，其余保持暗牌），可点「跳过」或按 Esc / Enter 直接进入。
- **发牌**：进入牌桌后，牌堆向五个座位各发四轮牌，手牌依次翻开；发牌期间不能操作。
- **左上**：轮次 / 阶段　**中上**：牌堆 / 弃牌数　**右上**：规则 / 记录 / **角色语音** / 音效 / 退出
- **中央**：最近一张打出的牌（含效果说明）
- **四周**：其他四人（立绘、体力、手牌数、**装备槽 ×4**、判定区、已知身份）
- **底部**：自己的角色卡（立绘、体力、**装备槽 ×4**、**技能区**）、手牌、行动按钮
  - 装备槽分 武器 / 防具 / 攻坐 / 防坐 四格，装了牌会亮起金色，点击查看详情；
  - 技能区每个技能都带类型标签（锁 / 主 / 触 / 限），本回合可发动的会发光并显示「N 个可发动」，已用过的会变暗；悬停查看完整说明。
- **每张手牌都印有效果说明**；鼠标悬停可看完整规则文本
- 出牌阶段：可出的牌会发光并标注「可出」，不可出的牌自动变暗，行动条会显示「可出 N 张」
- 选择目标时：可选角色会亮起红框并标注「选择目标」，鼠标悬停会从你脚下拉出一条金色预览线
- 出牌瞬间：出牌者与目标之间会拉出一条发光连线（颜色跟随卡牌），同时目标头像闪烁
- 点击自己的装备槽可以查看装备详情
- 右上角 **♪** 打开音乐播放器（暂停 / 切歌 / 音量）
- 需要响应时（回避 / 微声 / 反调 / 救援）会出战况提示条与「放弃」按钮
- 需要选牌时（拆台 / 读心 / 弃牌 / 弃代价）会弹出选择面板
- 快捷键：`Esc` 取消选择 / 关闭弹窗

## 七、账号与云存档

- 标题页「登录 / 注册」可以注册账号（用户名 2-16 位字母/数字/下划线/汉字、密码至少 4 位、可选昵称）。
- 账号数据保存在服务端 `data/users.json`：密码用 **scrypt + 随机盐** 存储，登录后发一个 HMAC 签名的 token（30 天有效），token 存在浏览器 `localStorage`。
- 登录后闯关存档（卡组 / 道具 / 强化 / 剧情进度 / 台词回顾）会自动同步到账号；换设备登录同一账号即可接着玩。
- 顶部按钮会显示昵称；登录弹窗里可以「从账号拉取存档」或「退出登录」。
- 服务端接口：`POST /api/auth/register`、`POST /api/auth/login`、`GET /api/auth/me`、`GET/PUT /api/save`（Bearer token）。
- 不登录也能玩（游客存档只在本机 `localStorage`）。

## 八、背景音乐

- 把动画歌曲（`.mp3 / .m4a / .ogg / .wav / .flac`）放进 **`music/`** 文件夹，刷新页面后会自动扫描并**随机循环播放**，文件名显示在播放器里。
- 没有放歌时，游戏会使用内置的 **5 首原创合成 BGM**（WebAudio 实时演奏，随机切换）。

- 仓库不附带任何版权音乐，请使用你合法持有的音源。

## 九、角色语音

- 覆盖 10 位成员（不含纯田真奈），共 **199 条**，来自你提供的本地语音包 `E:\bangdreamai\角色语音`。
- 导入时会读取音频文件的日文文件名（就是台词原文），按语义给每条打上**事件标签**，游戏里按事件取词：
  | 事件 | 触发时机 | 台词示例 |
  |---|---|---|
  | `attack` | 使用【微声】【对唱】【接唱】【聚光灯】 | 祥子「それは、どのくらいの覚悟で言ってるんですの？」 |
  | `skill` | 发动技能 | 睦「このままのほうが一生一緒にいられるよ」 |
  | `damage` | 受到伤害 | 祥子「ごめんなさい」 |
  | `heal` | 回复体力 | 祥子「ありがとうございます」 |
  | `equip` | 装备卡牌 | 海铃「確認ですが、あなた、ギター弾けませんよね」 |
  | `turn` | 回合开始（45% 概率） | 祥子「今日は言うことがあって来ましたの」 |
  | `death` | 退场 | 睦「私消えちゃうから」 |
  | `win` / `lose` | 胜利 / 失败结算 | 祥子「お幸せに」 |
- 每个事件每角色最多 3 条；没有合适台词时自动退回情绪池（battle / happy / hurt / cool）。
- 播放语音时，牌桌下方会弹出**台词字幕**：角色名 + 日文原文 + 中文翻译；即使关掉语音也会显示，方便看清她在说什么。215 条翻译都在 `voice/subtitles.js`。
- 右上角「声」按钮随时开关；音量跟随系统/浏览器音量。
- **行动节奏**：AI 每次出牌前会等当前语音播完（单次最多约 5 秒、整句最长约 7 秒），不会出现「话没说完就出牌」；关掉语音后恢复快速节奏。
- `voice/manifest.js` 保留每条语音的日文台词与事件标签，改 `events` 数组即可重映射，不需要重新转码。
- 处理方式：WAV 统一降采样为 16kHz 单声道，MP3 原样保留，浏览器直接播放。
- 注意：语音来自官方作品，仅供本地同人娱乐，请勿传播或商用。

## 十、剧情闯关

标题页第三项「剧情闯关」是一个视觉小说 + 卡牌战斗的闯关模式。

- **第一话「迷子の並行世界」**：Ave Mujica 演出结束，睦推开走廊尽头那扇不该存在的门，掉进"被剪掉的世界"。废弃教室里遇到和灯一模一样的"没被选上的声音"，随后与"影・祥子"开战。
- **第二话「雨の降らない屋上」**：第二扇门通往一座静止的屋顶，雨悬在半空。素世撑着一把没有雨的伞坐在屋檐边，说"我等了好久"。这一战要面对会拆你手牌的影・素世，胜利后拿到【吉他】（微声/对唱伤害 +1，可叠加）。
- **第三话「仮面の向こう」**：第三扇门后是那个舞台——灯还亮着，观众席空无一人。祥子拿着面具站在中央，说这个世界的歌都是她剪掉的："剪掉，就不会有人受伤。" 这一战祥子**每回合摸 2 张**、带【拆台】和【反调】，是第一章的 BOSS；胜利后拿到【反调】。通关后显示「第一幕 · 完」。
- **第四话「夜の校舎」**（第二幕）：睦自己推开那扇门，走进夜里的校舍。爱音抱着吉他弹着，却没有声音。随后影・立希撞开门——"用声音证明给我看"。这一战立希**每回合摸 2 张、双刀**（每回合最多两刀），胜利后拿到【合奏】（本回合伤害 +1）。
- **第五话「規則の在り処」**：门后是一间堆满乐谱和台本的事务所，桌上摊着「ルールブック」。写规则的人是另一个自己——**モーティス**。"ここにいれば、誰も選ばれない。" 这一战她带 **2 点护甲**（每次受伤 -2）、每回合摸 2、双刀，还会【反调】和【拆台】；胜利后拿到【仮面】（本场护甲 +1）。
- **第六话「灯のいない歌」**：录音室里没有声音，灯抱着膝盖坐在角落——她不是被剪掉，是自己唱不出来。"歌う理由が、わからなくなっちゃって。" 影・灯带 1 点护甲，而且**每次受伤都会摸 1 张牌**（把声音吸走）；胜利后拿到【歌】（1 伤 + 1 回复）。
- **第七话「規則の外側」**（第二幕·完）：事务所的墙透明了，四个人影站在四周。台本翻到最后一页——空白的。"終わらせない。それが、みんなの願いでしょう。" 这一战对手是「ルール」：12 血、2 护甲、每回合摸 2、三张【反调】两张【拆台】。胜利后拿到【独演】（3 伤，自伤 1），并显示「第二幕 · 完」。
- **第八话「最終幕」**（第三幕·完）：最后一扇门后是舞台，四支麦克风、一个空着的吉他架，幕布垂到脚边。四个人的声音同时从麦克风里响起。BOSS「終幕」14 血、2 护甲，**血量过半进入第二形态（护甲 +1、攻击 +1）**；胜利后拿到【終幕】（4 点伤害，每回合一次），主线到此刻告一段落。
- **视觉小说**：立绘 + 打字机台词 + 选项，支持「自动」「跳过对话」「退出」。背景用 CSS 渐变区分舞台 / 世界缝隙 / 教室 / 影之舞台 / 屋顶。
- **选项与收集**：
  - 1-1：追问身份→【微声】、问路→【灵感】、后退→【抹茶】；隐藏选项「打开吉他盒」→【应援棒】+ 道具「残破的节目单」。
  - 1-2：道歉→【灵感】、问身份→【拆台】、坐下→【抹茶】；隐藏选项「看她的伞」→ 道具「止まない傘」。
  - 1-3：制止她→【反调】、一起回去→【对唱】、弹吉他→【吉他】；隐藏选项「看节目单」→ 道具「褪色的节目单」。
- **卡组有限**：闯关模式从 9 张卡开始（微声×4 / 回避×3 / 抹茶×2），每关通关奖励一张新卡（对唱 / 吉他 / 反调）。奖励只发一次，重看不重复刷。
- **整理卡组**：章节页的「整理卡组（删卡）」可以移除多余卡牌（至少保留 8 张），方便把卡组压薄、提高关键牌上手率。
- **强化卡牌**：每关首次通关 +1 强化点，章节页「强化卡牌」里花 1 点把某一种卡永久升级（每种一次）：
  | 卡 | 强化后 |
  |---|---|
  | 微声 | 伤害 1 → 2 |
  | 回避 | 抵消后摸 1 张 |
  | 抹茶 | 回复 1 → 2 |
  | 对唱 | 伤害 2 → 3 |
  | 拆台 | 弃 1 → 2 张 |
  | 灵感 | 摸 2 → 3 张 |
  | 应援棒 | 护盾 1 → 2 |
  | 吉他 | 加成 1 → 2 |
  | 反调 | 抵消后摸 1 张 |
  | 合奏 | 加成 1 → 2 |
  | 仮面 | 护甲 1 → 2 |
  | 歌 | 伤害 1 → 2 |
  | 独演 | 伤害 3 → 4 |
  | 終幕 | 伤害 4 → 5 |
- **剧情回顾**：章节页「剧情回顾」可以按章节翻看已经读过的全部台词（含你选过的选项），没读过的章节不会出现。
- **成长**：通关第一幕后最大体力 6 → 7；卡组、强化、道具都跨关继承。
- **战斗**：1v1，双方 6～7 点体力；每回合摸 2 张，可打微声/抹茶/灵感/拆台/对唱/应援棒/吉他/合奏/仮面，被攻击时可打出【回避】，被【拆台】时可打出【反调】抵消。**护甲**会减免每次受到的伤害（最低 1 点）。血量为 0 判负，可原地重试。
- **影之试炼（无尽）**：通关第七话后解锁。用你的卡组一波波打随机影子，敌人血量、攻击、护甲随波数上升；每 3 波给 1 点强化点，**每 5 波额外掉落一张新卡**，记录最佳波数（随账号同步）。最终幕之后，卡组和强化在这里继续有用。
- **新增卡牌**（试炼掉落）：
  | 卡 | 效果 |
  |---|---|
  | 本番 | 造成 2 点伤害；本回合已用【微声】则改为 4 点 |
  | 照明 | 对手随机弃 1 张，你摸 1 张 |
  | 衣装 | 获得 1 点护盾，摸 1 张 |
  | アンコール | 回复 2 点体力，摸 1 张 |
  | 静寂 | 对手下回合少摸 1 张 |
  这五张都可以在「强化卡牌」里升级。
- **战斗表现**（对齐经典模式）：开局有发牌动画（牌从牌堆飞到手上）、出牌时卡牌从手牌飞到中央、攻击/拆牌会从中央拉出指示线指向对手、受击/回复有震屏与粒子。
- **关卡解锁**：章节按顺序解锁，1-1 通关后才会出现 1-2 的「进入关卡」。
- **存档**：卡组、道具、通关状态存在 `localStorage`（`jgs.campaign.v1`），章节页可清空重来。

新增关卡只要在 [js/story.js](jigousha/js/story.js) 里加一个章节对象（节点/选项/战斗），再在章节页列出即可。

## 十二、技术说明

- **单一规则引擎**：`engine.js` 同时运行在浏览器（经典模式）与 Node（联机模式），规则只有一份实现。
- **生成器驱动结算**：所有需要玩家响应的时机（闪避、救援、反调、技能确认）以 `yield` 挂起，服务端推进，天然支持嵌套结算。
- **服务端权威**：联机模式下服务器持有完整状态，只向每名玩家下发投影视图（自己的手牌、公开信息、隐藏身份为空），前端不做规则判定。
- **零依赖**：WebSocket 服务端为手写实现（RFC6455 文本帧），不需要安装任何包。
- **账号**：`data/users.json` 存用户（scrypt 加盐哈希 + HMAC token），闯关存档随账号云同步；不登录时退回 localStorage。
- **战斗特效**：`JGSFx` 统一提供粒子（受击红 / 回复绿 / 退场紫）与震屏，经典、联机、闯关共用；动画只动 `transform` / `opacity`，不吃帧。
- **AI 不作弊**：只使用自己可见的信息（自己的身份、公开身份、手牌数量、装备、伤害历史）决策。
- **AI 决策要点**：优先斩杀残血目标；避开「无手牌 + 耳返」的免疫目标；对拿着应援棒的目标降权；拆台/挖角优先拆对手的武器防具；【练习】会留到下一张【微声】之前用；【对唱】专挑手牌少、血少的对手；反调只在真正亏的时候交。

## 十三、性能与帧率

- **帧率上限由显示器决定**：浏览器用 `requestAnimationFrame` 渲染，60Hz 屏幕最多 60 FPS，90Hz 屏幕才会到 90 FPS，144Hz 同理。页面本身不会锁 60。
- 已做过的优化：
  - 背景两团 `filter: blur(90px)` 的发光光斑 → 改成径向渐变（不再每帧重算模糊）；
  - 去掉 `backdrop-filter`（弹窗遮罩、音乐面板、日志面板）与多处无限循环的 `box-shadow` 动画（回合高亮、可选中脉冲、音乐按钮）；
  - 保留的动画都只动 `transform` / `opacity`（合成层，不触发重绘）。
- **看帧率**：按 `F` 或打开 `http://localhost:8787/?fps=1`，右下角会显示实时 FPS。
- **低配模式**：`http://localhost:8787/?perf=1` 会关闭背景光斑动画与装饰动画，适合核显 / 老机器。
