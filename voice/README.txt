角色语音（本地音源 · 按事件编目）
==================================

本目录由 tools/voice_import.py 从本地语音包生成：

- 音源：E:\bangdreamai\角色语音\Mujica 与 MyGO!!!!!（用户提供的本地文件）
- 覆盖：10 位成员（高松灯 / 千早爱音 / 要乐奈 / 长崎素世 / 椎名立希 /
  丰川祥子 / 若叶睦（含 Mortis）/ 三角初华 / 八幡海铃 / 祐天寺喵梦）
  纯田真奈没有语音包，因此没有语音。
- 共 215 条。导入时读取文件的日文文件名（即台词原文），按语义打上事件标签：

  attack  出牌（微声 / 对唱 / 接唱 / 聚光灯）
  skill   发动技能
  damage  受到伤害
  heal    回复体力
  equip   装备卡牌
  turn    回合开始
  death   退场
  win     胜利
  lose    失败

- 每个事件每角色最多 3 条；某个事件没有合适台词时，自动退回四类情绪池
  （battle / happy / hurt / cool，见 manifest.js 末尾的 JGSVoiceMood）。
- 播放时牌桌下方会显示字幕（角色名 + 日文 + 中文），翻译在 subtitles.js，
  按 manifest 里的 id 对应；即使关闭语音，字幕仍会显示。
- WAV 降采样为 16kHz 单声道，MP3 原样保留，总体积约 14MB。
- 右上角「声」按钮可随时开关。

想改映射：直接编辑 manifest.js 里每条记录的 events 数组即可，不用重新转码。
想改字幕：编辑 subtitles.js 里对应 id 的中文即可。

仅供本地同人娱乐使用，请勿传播或商用。
